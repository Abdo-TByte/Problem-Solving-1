# Days to Years, Months, and Days Converter

This is a simple C++ program that converts a given number of days into years, months, and remaining days. It assumes that:
- A year consists of 365 days.
- A month consists of 30 days.

## How It Works

1. The program takes an integer input from the user, representing the total number of days.
2. It calculates:
   - The number of years by dividing the total days by 365.
   - The remaining days after extracting years.
   - The number of months by dividing the remaining days by 30.
   - The remaining days after extracting months.
3. Finally, it outputs the result in the format of years, months, and days.
